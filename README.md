# Online Food Delivery System

## Project Description

The Online Food Delivery System is a web-based application
that allows users to view food items, register an account,
login, add food to a cart, and place food orders online.

## Features

- User Registration
- User Login
- User Logout
- Food Menu
- Shopping Cart
- Food Ordering
- Order History
- Contact Form
- Responsive Design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL/MariaDB
- XAMPP
- Git/GitHub

## Database

The system uses MySQL/MariaDB to store:

- Users
- Food items
- Orders
- Order items
- Contact messages
